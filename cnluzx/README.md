# 小车硬件模块测试与标定工具箱 (cnluzx)

本目录为小车各底层硬件模块提供独立的诊断、测试与标定脚本，方便在不跑大程序的情况下，单项排查舵机、电机、激光雷达、IMU 惯导、编码器与摄像头的工作状态。

---

## 快速开始

进入本目录并加载 ROS 2 环境后，运行控制台主菜单：

```bash
source /opt/ros/humble/setup.bash
source ~/racecar/install/setup.bash
cd ~/racecar/cnluzx

# 启动交互式综合测试控制台：
python3 menu.py
```

您也可以直接单独运行任意一个测试脚本。

## 各测试模块使用说明

### 1. 舵机转向测试与标定 (`test_servo.py`)
* **运行命令**：`python3 test_servo.py`
* **测试目的**：验证前轮物理机械转角（-45° ~ +45°）与算法指令角度（0° ~ 180°）的一致性，标定小车直行中位。
* **物理与算法对应关系**：
  * **中位直行**：物理 $0^\circ \longleftrightarrow$ 算法指令 $82.5^\circ \longleftrightarrow$ 舵机 PWM $1583\,\mu\text{s}$
  * **最大左转**：物理 $+45^\circ \longleftrightarrow$ 算法指令 $180.0^\circ \longleftrightarrow$ 舵机 PWM $500\,\mu\text{s}$
  * **最大右转**：物理 $-45^\circ \longleftrightarrow$ 算法指令 $0.0^\circ \longleftrightarrow$ 舵机 PWM $2500\,\mu\text{s}$
  * *换算比例：每 $1^\circ$ 物理前轮转角 $\approx 2.17^\circ$ 算法指令角 $\approx 22.2\,\mu\text{s}$ 底层脉宽*
* **主要功能**：
  * **[1] 立即回中**：车轮迅速回到 $82.5^\circ$ 中位。
  * **[2] 5点阶梯标定**：自动依次打到 $-45^\circ \to -22.5^\circ \to 0^\circ \to +22.5^\circ \to +45^\circ$，每个位置停留 2 秒，可用量角器检查车轮实际角度。
  * **[3] 平滑往复摆动 (Sweep)**：检查连杆机构是否卡顿或干涉。
  * **[4] 键盘实时微调**：按 `A/D` 键以 $1^\circ$ 为步长微调。若发现车轮在某角度（如 $84.0^\circ$）最平直，可将 `param.yaml` 中的 `servo_center` 设为此值。

---

### 2. 驱动电机安全测试 (`test_motor.py`)
* **运行命令**：`python3 test_motor.py`
* **测试目的**：测试电调 (ESC) 与驱动电机响应，检查前进/刹车/后退平顺度。
* **安全提示**：**测试前强烈建议将小车垫高，使驱动轮悬空离地！**
* **控制参数定义 (PWM)**：
  * `1500.0`：停止（中位刹车）
  * `1525.0`：低速微转（适合架空测试电机转动方向）
  * `1540.0`：巡航速度（循迹算法默认基准车速）
  * `1560.0`：较快车速
* **主要功能**：
  * 提供了限时安全转动（2秒自动停机）、平滑加速减速曲线测试，以及带安全范围（1450~1580）的手动输入测试。按 Ctrl+C 可立即紧急断电。

---

### 3. 激光雷达实时诊断 (`test_laser.py`)
* **运行命令**：`python3 test_laser.py`
* **测试目的**：检查雷达通信速率、有效点云比例以及各方位的障碍物测距。
* **主要功能**：
  * 终端 ASCII 实时仪表盘刷新。
  * 实时显示 5 个核心扇区距离：正前方 $0^\circ$、左前 $45^\circ$、右前 $-45^\circ$、正左 $90^\circ$、正右 $-90^\circ$。
  * 实时定位全周最近障碍物的准确距离与角度方位。
  * *若雷达未旋转或未出数，请检查驱动或执行：`ros2 topic pub -1 /lslidar_order std_msgs/msg/Int8 data:\ 1`*

---

### 4. IMU 姿态与陀螺仪测试 (`test_imu.py`)
* **运行命令**：`python3 test_imu.py`
* **测试目的**：检查九轴/六轴惯导的航向角、自转角速度和静止温漂。
* **主要功能**：
  * **实时姿态监视**：实时解算四元数为欧拉角，显示航向角 (Yaw)、俯仰角 (Pitch)、横滚角 (Roll)、三轴角速度及加速度。
  * **静止零偏漂移测试**：小车静止 6 秒，自动计算 Yaw 漂移率（度/分钟），评估陀螺仪零漂是否合格。
  * **航向一键清零**：按空格键将当前朝向设为 $0^\circ$，方便手动将小车转动 $90^\circ$ 或 $180^\circ$ 检验角度测量是否精准。

---

### 5. 轮速编码器与里程计测试 (`test_encoder.py`)
* **运行命令**：`python3 test_encoder.py`
* **测试目的**：检查轮速传感器通信及里程计累积距离的准确性。
* **主要功能**：
  * 实时显示底层轮速计的线速度 ($m/s$) 及融合里程计坐标 $(X, Y)$。
  * **推车测距标定助手**：在地面画出 1.00 米直线，按回车开始推车，推到终点后自动比对测量距离与真实距离，计算出轮径修正比例系数！

---

### 6. 摄像头视觉测试 (`test_vision.py`)
* **运行命令**：`python3 test_vision.py`
* **测试目的**：测试 USB 摄像头连通性、成像质量与帧率。
* **主要功能**：
  * **[1] 硬件检测与抓拍**：测试打开 `/dev/video0`，测算采集 FPS，并截取一张测试图片保存为 `camera_test.jpg`。
  * **[2] Web 实时图传**：在小车端启动微型视频流服务（端口 8081）。电脑或手机直接在浏览器输入 `http://192.168.5.4:8081` 即可远程实时查看摄像头画面，调焦或调整视角极度方便！
